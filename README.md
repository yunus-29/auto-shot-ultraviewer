# Auto Shot Ultraviewer

Repositori ini berisi alat untuk membantu menangkap dan menyimpan screenshot secara otomatis pada saat menjalankan aplikasi UltraViewer atau kebutuhan monitoring yang membutuhkan capture berkala.

## Fitur
- Capture otomatis
- Output sederhana dan mudah dipelajari
- Cocok untuk dokumentasi dan monitoring
- Mudah dikembangkan sesuai kebutuhan

## Persyaratan
- Windows
- UltraViewer terinstal
- Python 3.10+ (jika digunakan bersama script)
- Folder output yang siap ditulis

## Struktur
- `auto.zip` berisi file utama / script pendukung
- `README.md` berisi dokumentasi proyek

## Cara Pakai
1. Unduh atau clone repositori ini.
2. Ekstrak file ZIP yang dibutuhkan.
3. Jalankan file yang relevan sesuai kebutuhan.
4. Pastikan folder output tersedia sebelum proses dijalankan.

## Catatan
Proyek ini masih dalam tahap pengembangan dan dapat disesuaikan lebih lanjut tergantung kebutuhan penggunaan.
